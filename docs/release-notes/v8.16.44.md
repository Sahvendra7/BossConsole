# BOSS v8.16.44

**Release Date:** 2026-02-12

RPA recorder plugin browser support and browser profile cleanup improvements for better resource management and automation capabilities.

## Highlights

- **RPA Recorder Plugin Support**: RPA recorder now works with dynamic plugin browser tabs, eliminating "No browser connection" errors
- **Enhanced Profile Cleanup**: Comprehensive browser profile cleanup on startup with orphaned process detection

## Bug Fixes

- **browser**: Support dynamic plugin browser tabs in RPA recorder (#627)
  - Fixed RPA recorder showing "No browser connection" for dynamic plugin browser tabs
  - Added support for FluckBrowserTabData from fluck-browser plugin
  - Implemented reflection-based URL/favicon extraction for plugin tabs
  - Added BrowserServiceImpl fallback for browser handle lookup
  - Enhanced tab detection to recognize typeId == "fluck" alongside built-in FluckTabInfo

- **browser**: Improve browser profile cleanup on startup
  - Kill orphaned chrome_crashpad processes with dead parent detection
  - Delete ALL temporary browser profiles at startup (not just >24h old)
  - Use Files.deleteIfExists for lock file symlinks on macOS for more reliable cleanup
