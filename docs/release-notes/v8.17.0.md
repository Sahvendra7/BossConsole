# BOSS v8.17.0

**Release Date:** 2026-02-12

Enhanced passkey authentication with full WebAuthn support in BOSS's embedded Chromium browser.

## Highlights

- **Native Passkey Support**: Complete WebAuthn/passkey support in embedded Chromium for seamless passwordless authentication

## Features

- **browser**: Enable WebAuthn/passkey support in embedded Chromium (#628)
  - Implemented native WebAuthn support in JxBrowser-based embedded browser
  - Enabled passkey registration and authentication flows directly within BOSS
  - Integrated with DesktopPasskeyService for credential management
  - Eliminates need for external browser redirects during authentication
