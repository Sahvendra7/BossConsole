# BOSS v8.16.45

**Release Date:** 2026-02-12

WebAuthn/passkey support for embedded Chromium browser with improved macOS code signing and UI enhancements.

## Highlights

- **WebAuthn/Passkey Support**: Full WebAuthn and passkey authentication support in BOSS's embedded Chromium browser (JxBrowser 8.17.0)
- **Enhanced macOS Security**: Improved Chromium binary re-signing for macOS with client-side inside-out approach
- **Better UX**: Fixed Chromium download dialog to properly show action buttons

## Features

- **browser**: Enable WebAuthn/passkey support in embedded Chromium (JxBrowser)
  - Upgraded JxBrowser to 8.17.0 with WebAuthn capabilities
  - Enables full passkey authentication workflows in embedded browser
  - Improves security and user experience for credential management

## Bug Fixes

- **browser**: Re-sign macOS Chromium binaries after zip extraction
  - Implemented client-side inside-out re-signing for macOS binaries
  - Reverted CI re-signing to ad-hoc approach
  - Ensures proper code signing compliance on macOS

- **browser**: Increase Chromium download dialog height to show buttons
  - Fixed dialog layout to properly display action buttons
  - Improves user experience during browser engine download

- **build**: Add platform binary to downloadChromium task classpath
  - Fixed classpath configuration for Chromium download task
  - Ensures proper resource loading during build process

## Dependencies

- **JxBrowser**: Upgraded to 8.17.0 for WebAuthn support
